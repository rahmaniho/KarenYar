این پوشه مستندات ممیزی، اصلاح، آزمون و استقرار ماژول فاکتور است.

| سند                                                | کاربرد                                                                                    |
| -------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| [`initial-audit.md`](./initial-audit.md)           | ممیزی اولیه، شواهد و اولویت‌بندی INV-01…INV-15                                            |
| [`delivery-report.md`](./delivery-report.md)       | گزارش نهایی: اصلاحات، فایل‌ها، schema/API، نتایج آزمون، محدودیت‌ها                        |
| [`user-guide.md`](./user-guide.md)                 | راهنمای کاربر: پیش‌نویس، صدور، دریافت/برگشت وجه، ابطال، چاپ/PDF، فیلترها                  |
| [`migration-rollback.md`](./migration-rollback.md) | راهنمای مهاجرت IndexedDB v3→v4، پشتیبان‌گیری v3 و rollback                                |
| [`audit/`](./audit/)                               | خروجی خام آزمون‌ها: `typecheck.txt`، `lint.txt`، `unit-tests.txt`، `e2e.txt`، `build.txt` |

## وضعیت نهایی آزمون‌ها

- `npm run typecheck`: موفق
- `npm run lint -- --max-warnings 0`: موفق
- `npm test`: **42 فایل / 312 آزمون موفق**
- `npm run test:e2e`: **30 آزمون موفق** (Chromium دسکتاپ + Pixel 7 موبایل)
- `npm run build`: موفق؛ هشدار حجم chunk PDF برداری باقی است ولی PDF فقط هنگام درخواست بارگذاری می‌شود.

## پیش‌نمایش

سرور توسعه با `npm run dev -- --host 0.0.0.0 --port 5173` اجرا شده است. دادهٔ نمایشی فقط در محیط DEV و با اقدام صریح کاربر تولید می‌شود؛ در build عملیاتی غیرفعال است.

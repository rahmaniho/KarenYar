# لوگوی رسمی حساب‌یار

دو فایل منبع رسمی در `scripts/assets/` نگهداری می‌شوند:

- `hesabyar-app-icon.png`: آیکون مربعی آپلودشده؛ منبع آیکون برنامه، PWA و نشان‌های کوچک سایت.
- `hesabyar-logo.png`: وردمارک کامل و شفاف حساب‌یار؛ منبع لوگوی وب و اسپلش اندروید.

فایل‌های تولیدشده را مستقیم ویرایش نکنید؛ آن‌ها را از منابع رسمی بازسازی کنید.

## خروجی‌ها

| فایل                                                 | کاربرد                                                               |
| ---------------------------------------------------- | -------------------------------------------------------------------- |
| `public/images/hesabyar/mark.png`                    | آیکون رسمی در سایدبار، هدر موبایل، آواتار، چاپ/PDF فاکتور و فیش حقوق |
| `public/images/hesabyar/logo.png`                    | وردمارک کامل در صفحهٔ قفل و بخش «درباره» تنظیمات                     |
| `public/images/hesabyar/app-icon.png`                | آیکون مربعی برنامه (۵۱۲×۵۱۲)                                         |
| `public/icons/icon-192.png`                          | favicon و آیکون PWA                                                  |
| `public/icons/icon-512.png`                          | آیکون PWA و منبع لانچر Android                                       |
| `public/icons/icon-maskable-512.png`                 | آیکون maskable PWA                                                   |
| `public/icons/apple-touch-icon.png`                  | آیکون iOS                                                            |
| `android/app/src/main/res/mipmap-*/ic_launcher*.png` | لانچر Android                                                        |
| `android/app/src/main/res/drawable*/splash.png`      | اسپلش Android با وردمارک کامل                                        |

## بازتولید

```bash
pip install pillow
npm run icons:hesabyar
```

این دستور ابتدا `scripts/build-app-logo.py` و سپس `scripts/build-android-icons.py` را اجرا می‌کند.

## نکته‌های برند

- آیکون مربعی رسمی برای آیکون لانچر و نشان‌های کوچک استفاده می‌شود.
- وردمارک کامل شامل «حساب‌یار / Hesabyar / Powered by KarenSoft» است؛ شفافیت آن حفظ و حاشیهٔ شفاف اضافی به‌طور خودکار بریده می‌شود.
- در سایت، وردمارک روی زمینهٔ سفید قرار می‌گیرد تا نوشته‌های سرمه‌ای خوانا بمانند.
- اعتبار vendor «طراحی و توسعه توسط کارن سافت» در `KarenSoftCredit` همچنان از نشان و وردمارک کارن‌سافت استفاده می‌کند و با لوگوی حساب‌یار جایگزین نشده است.
- اسپلش اندروید روی پس‌زمینهٔ تیره و وردمارک روی زمینهٔ سفیدِ گوشه‌گرد ساخته می‌شود تا نوشتهٔ سرمه‌ای خوانا باشد.

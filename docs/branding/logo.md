# لوگوی رسمی کارو — نرم‌افزار حسابداری

یک فایل منبع رسمی در `scripts/assets/` نگهداری می‌شود:

- `karo-logo.png`: وردمارک کامل کارو (نشان رنگی + نوشتهٔ سفید «کارو») با پس‌زمینهٔ شفاف؛ منبع همهٔ لوگوها، آیکون‌ها و اسپلش‌ها.

فایل‌های تولیدشده را مستقیم ویرایش نکنید؛ آن‌ها را از منبع رسمی بازسازی کنید.

## خروجی‌ها

| فایل                                                 | کاربرد                                                                    |
| ---------------------------------------------------- | ------------------------------------------------------------------------- |
| `public/images/karo/logo.png`                        | وردمارک کامل و شفاف در سایدبار، صفحهٔ قفل، بخش «درباره» تنظیمات و اسپلش   |
| `public/images/karo/mark.png`                        | نشان مربعی روی کاشی تیره در هدر موبایل، آواتار، چاپ/PDF فاکتور و فیش حقوق |
| `public/images/karo/app-icon.png`                    | آیکون مربعی برنامه (۵۱۲×۵۱۲)                                              |
| `public/icons/icon-192.png`                          | favicon و آیکون PWA                                                       |
| `public/icons/icon-512.png`                          | آیکون PWA و منبع لانچر Android                                            |
| `public/icons/icon-maskable-512.png`                 | آیکون maskable PWA                                                        |
| `public/icons/apple-touch-icon.png`                  | آیکون iOS                                                                 |
| `android/app/src/main/res/mipmap-*/ic_launcher*.png` | لانچر Android                                                             |
| `android/app/src/main/res/drawable*/splash.png`      | اسپلش Android با وردمارک کامل روی پس‌زمینهٔ مشکی                          |

## بازتولید

```bash
pip install pillow
npm run icons:karo
```

این دستور ابتدا `scripts/build-app-logo.py` و سپس `scripts/build-android-icons.py` را اجرا می‌کند.

## نکته‌های برند

- وردمارک کارو **سفید** است؛ روی سطوح تیره (سایدبار شیشه‌ای سرمه‌ای، اسپلش مشکی) مستقیم استفاده می‌شود.
- روی سطوح روشن یا تم روشن، لوگو داخل کاشی مشکیِ گوشه‌گرد قرار می‌گیرد تا نوشتهٔ سفید خوانا بماند
  (صفحهٔ قفل و بخش «درباره»).
- نشان مربعی از بخش رنگی لوگو ساخته می‌شود و روی کاشی مشکی می‌نشیند؛ همین طرح، آیکون برنامه و PWA است.
- رنگ‌های نشان: نارنجی/طلایی `#F5A623`، آبی `#22A7DC`؛ پس‌زمینهٔ کاشی مشکی است.
- اعتبار vendor «طراحی و توسعه توسط کارن سافت» در `KarenSoftCredit` همچنان از نشان و وردمارک کارن‌سافت
  استفاده می‌کند و با لوگوی کارو جایگزین نشده است.
- شناسه‌های فنیِ قدیمی (`ir.karensoft.hesabyar`، `product_code = hesabyar`، کلیدهای `hesabyar-*` در
  localStorage) برای سازگاری با نصب‌ها و لایسنس‌های موجود تغییر نکرده‌اند؛ فقط برند نمایشی «کارو» شده است.

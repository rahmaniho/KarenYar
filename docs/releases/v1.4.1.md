# حساب‌یار اندروید 1.4.1

بیلد نگه‌داری بر پایهٔ کد برنامهٔ 1.4.0، با نسخهٔ جدید `1.4.1` و `versionCode=10401`. آیکون اندروید/PWA و نشان‌های سایت با آیکون مربعی رسمی و وردمارک کامل به‌روزرسانی شده‌اند؛ در منطق مالی برنامه تغییری اعمال نشده است.

- شناسهٔ برنامه: `ir.karensoft.hesabyar`
- حداقل اندروید: ۷ (API 24)
- هدف SDK: 36
- نوع خروجی این ساخت: APK آزمایشی با امضای استاندارد Android Debug؛ مناسب فروشگاه‌ها نیست.

**پیش از حذف نسخهٔ قبلی، از داده‌های محلی برنامه پشتیبان JSON بگیرید.** این APK آزمایشی ممکن است به‌دلیل تفاوت امضا روی نسخهٔ انتشار نصب نشود. برای انتشار در فروشگاه باید با همان کلید خصوصی انتشار قبلی، یک Release امضاشده ساخته شود.

# حساب‌یار اندروید 1.4.0

نسخهٔ انتشار امضاشدهٔ حساب‌یار کارن سافت، با شناسهٔ `ir.karensoft.hesabyar` و `versionCode=10400`.

## تغییرات این نسخه

- بازطراحی ماژول فاکتور و محاسبات دقیق پول، تخفیف و مالیات.
- پیش‌نویس، ویرایش و کپی فاکتور؛ دریافت جزئی/کامل، برگشت وجه و اصلاح پرداخت با حفظ سابقه.
- جلوگیری از ثبت پرداخت تکراری و ابطال تراکنشی با اصلاح موجودی و درآمد.
- مرکز فاکتورها، فیلتر و جست‌وجو، داشبورد و هماهنگی چاپ/PDF.
- پشتیبان‌گیری نسخهٔ ۳ و مهاجرت افزایشی پایگاه دادهٔ محلی به نسخهٔ ۴.
- لوگوی رسمی جدید حساب‌یار در برنامه، آیکون لانچر و اسپلش اندروید.

## دریافت و نصب

- `hesabyar-1.4.0.apk`: نصب مستقیم روی گوشی.
- `hesabyar-1.4.0.aab`: بستهٔ انتشار برای فروشگاه‌های نیازمند AAB.
- `SHA256SUMS.txt`: اثر انگشت فایل‌های انتشار.
- حداقل اندروید: ۷، API 24؛ هدف SDK: 36.
- قابلیت‌های اصلی مالی و ذخیرهٔ داده‌ها آفلاین است.

## پیش از به‌روزرسانی

**از داخل برنامه خروجی پشتیبان JSON بگیرید و آن را بیرون از دستگاه نگه دارید.** مهاجرت پایگاه داده افزایشی است، اما پشتیبان پیش از به‌روزرسانی همچنان ضروری است. راهنمای مهاجرت و بازیابی در `docs/invoices/migration-rollback.md` است.

اگر نسخهٔ فعلی شما APK آزمایشی/Debug باشد، ممکن است امضای آن با این نسخهٔ Release متفاوت باشد و اندروید اجازهٔ به‌روزرسانی مستقیم ندهد. در این حالت، فقط پس از اطمینان از سلامت پشتیبان، نسخهٔ قبلی را حذف و نسخهٔ جدید را نصب کنید؛ حذف برنامه داده‌های محلی آن را پاک می‌کند. برای انتشارهای بعدی از همان کلید Release استفاده شود.

این انتشار به معنی بارگذاری یا تأیید در بازار، گوگل‌پلی یا فروشگاه دیگری نیست. فایل‌های امضاشده برای بارگذاری جداگانه در پنل فروشگاه مربوط آماده می‌شوند. موفقیت ساخت و بررسی امضا جای آزمون روی دستگاه واقعی را نمی‌گیرد.

# دموی امن کارو (نسخهٔ سروری)

دمو یک **فروشگاه واقعیِ کوتاه‌عمر و کاملاً جدا** است که از صفحهٔ ورود با یک کلیک
ساخته می‌شود تا کاربر بدون ثبت‌نام و بدون پرداخت، برنامه را با دادهٔ نمونه ببیند.
این قابلیت «نمایش محصول» است، نه پرداخت یا فعال‌سازی جعلی.

## جریان کاربر

1. صفحهٔ ورود → دکمهٔ **«ورود به دموی امن»** (`POST /api/demo/session`).
2. سرور فروشگاه دمو + کاربر + لایسنس آزمایشی (ساعت‌محور) + دادهٔ نمونه می‌سازد و
   کاربر را با نشست لاراول وارد می‌کند (بازگشت `201`).
3. در بالای همهٔ صفحه‌ها نوار زرد «حالت دمو» با **زمان باقی‌مانده** دیده می‌شود:
   - «ساخت فروشگاه واقعی» → پایان دمو، پاک‌سازی داده و باز شدن صفحهٔ ثبت‌نام.
   - «پایان دمو» → `DELETE /api/demo/session` و پاک‌سازی فوری داده.
4. اگر کاربر کاری نکند، زمان‌بند سرور دموی منقضی را پاک می‌کند.

## قواعد امنیتی (پیاده‌شده)

| قاعده | جزئیات |
| --- | --- |
| بدون دادهٔ جعلی مالی | هیچ `orders` یا `subscription_payments` در دمو ساخته نمی‌شود؛ لایسنس `is_trial` واقعی است |
| جدایی کامل داده | همهٔ جدول‌های عملیاتی `store_id` دارند و با `cascadeOnDelete` پاک می‌شوند |
| ایمیلی قابل سوءاستفاده نیست | ایمیل کاربر دمو `demo-<code>@demo.invalid` است (دامنهٔ رزروشده) و رمز تصادفی ۳۲ نویسه دارد |
| جدایی از آمار مدیر | دموها در داشبورد (درآمد، MRR، مشترکان، فروشگاه‌ها) و فهرست مشترکان شمرده نمی‌شوند |
| عملیات حساس بسته | میان‌افزار `not.demo` روی خرید/تمدید اشتراک، ساخت/ویرایش عضو تیم، `sync/wipe` و `sync/import` |
| پایان عمر | `stores.demo_expires_at`؛ ورود و مسیرهای داده پس از آن `403/422` می‌دهند و داده پاک می‌شود |
| محدودیت نرخ | `throttle:6,60` روی ساخت دمو (۶ بار در ساعت برای هر IP/نشست) |
| سقف هم‌زمانی | `KARO_DEMO_MAX_ACTIVE` (پیش‌فرض ۴۰) با پاک‌سازی خودکار منقضی‌ها پیش از ساخت |
| ممیزی | `demo_created`، `demo_closed_by_user`، `demo_ended` (شامل منقضی‌شده) |

## پیکربندی

```dotenv
KARO_DEMO_ENABLED=true     # خاموش کردن دمو از صفحهٔ ورود
KARO_DEMO_HOURS=24         # عمر دمو (۱ تا ۷۲ ساعت)
KARO_DEMO_MAX_ACTIVE=40    # سقف دموی فعال هم‌زمان
KARO_DEMO_SEED=true        # ساخت دادهٔ نمونه (۸ کالا، ۴ مشتری، ۷ فاکتور)
```

## API

| مسیر | توضیح |
| --- | --- |
| `POST /api/demo/session` | ساخت دمو و ورود فوری (عمومی، throttle ۶/ساعت) |
| `DELETE /api/demo/session` | پایان دمو و حذف کامل داده (فقط کاربر دمو) |
| `GET /api/sync/pull` | دادهٔ نمونه از همان مسیر همگام‌سازی عادی خوانده می‌شود |

## عملیات و نگهداری

```bash
php artisan karo:demo:purge            # پاک‌سازی دموهای منقضی
php artisan karo:demo:purge --dry-run  # فقط شمارش
```

`routes/console.php` این دستور را **هر ساعت** زمان‌بندی می‌کند؛ روی سرور تنها
`php artisan schedule:run` با cron لازم است.

## دادهٔ نمونه

۸ کالا در ۴ دسته، ۴ مشتری، ۶ فاکتور فروش (دو نسیه) و یک فاکتور **باطل‌شده** با دلیل —
همه با شمارندهٔ `rev` درج می‌شوند تا کلاینت سروری در اولین `pull` آن‌ها را بگیرد.
مبالغ واقعی و قابل محاسبه‌اند (مالیات ۱۰٪) تا گزارش‌ها معنادار باشند.

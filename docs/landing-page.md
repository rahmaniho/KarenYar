# صفحهٔ معرفی (لندینگ) — نسخهٔ سروری کارو

ریشهٔ برنامه (`/`) برای بازدیدکنندهٔ **واردنشده** یک صفحهٔ معرفی فارسی است؛ کاربر
واردشده همچنان مستقیم به برنامهٔ فروشگاه یا پنل مدیر می‌رود.

## جریان ورود به برنامه

```
/  ──(لندینگ)──┬── «امتحان دموی امن» ────► فروشگاه دمو (موقت) ──► نوار دمو ──► «ساخت فروشگاه واقعی»
               ├── «شروع رایگان» ───────► ثبت‌نام ──► دورهٔ آزمایشی ──► داخل برنامه
               ├── «شروع با این پلن» ───► ثبت‌نام ──► /subscription با پلن preselected ──► پرداخت ──► لایسنس فعال
               └── «ورود» ──────────────► ورود با ایمیل/رمز ──► برنامه
```

- پس از پرداخت (زرین‌پال یا کارت‌به‌کارت با تأیید مدیر) لایسنس فعال می‌شود و همان
  نشست کاربر او را داخل برنامه می‌برد.
- با پایان یا تعلیق اشتراک، دسترسی محدود می‌شود اما داده حذف نمی‌شود.
- اگر ثبت‌نام عمومی خاموش باشد (`KARO_PUBLIC_SIGNUP=false`)، دکمه‌های ثبت‌نام از
  لندینگ حذف می‌شوند و فقط دمو/ورود می‌ماند.

## بخش‌های صفحه

| بخش | محتوا |
| --- | --- |
| هدر | لوگو، لنگرهای «ویژگی‌ها/دمو/تعرفه‌ها/پرسش‌ها»، دکمهٔ ورود و شروع رایگان |
| قهرمان | تیتر معرفی، توضیح، دکمه‌های ثبت‌نام و دمو، خلاصهٔ مزیت‌ها، پیش‌نمایش نمونهٔ داشبورد (برچسب «نمونه») |
| ویژگی‌ها | ۸ کارت: صندوق، فاکتور، انبار، مشتریان، حقوق، مالی، ابزارها، آفلاین/اندروید |
| دمو | توضیح دموی امن + سه گام شروع |
| تعرفه‌ها | کارت پلن‌ها از API عمومی؛ قیمت ماهانه، کاربر اضافه، فهرست ویژگی‌ها |
| پرسش‌ها | ۵ پرسش متداول (داده، آفلاین، دمو، پایان اشتراک، پرداخت) |
| فراخوان پایانی + فوتر | ساخت فروشگاه، ورود، لینک karen-soft.ir |

## منبع داده

- تعرفه‌ها: `GET /api/subscription/plans` (عمومی، فقط پلن‌های فعال) — هیچ قیمتی در
  کد فرانت ثابت نیست؛ `trial_days`، `currency_label` و `public_registration` هم از
  همان پاسخ می‌آیند.
- اگر API در دسترس نباشد، پیام جایگزین با راهنمای ورود نمایش داده می‌شود (صفحه
  نمی‌شکند).
- دمو: `POST /api/demo/session` (جزئیات در [`demo-mode.md`](./demo-mode.md)).

## رفتار مسیرها

- `/` → لندینگ (مهمان) / برنامه (واردشده).
- `/store/...`، `/subscription`، `/admin` برای مهمان → مستقیم صفحهٔ ورود (لینک عمیق
  گم نمی‌شود).
- پس از «پایان دمو» → صفحهٔ ثبت‌نام باز می‌شود.
- انتخاب پلن در لندینگ در `sessionStorage` (`karo:signup-plan`) نگه داشته می‌شود؛
  پس از ثبت‌نام کاربر به `/subscription` می‌رود و همان پلن انتخاب‌شده است.

## فایل‌ها

- `frontend-overlay/features/landing/LandingPage.tsx` — صفحه
- `frontend-overlay/features/landing/landing-content.ts` — متن‌ها/ویژگی‌ها/پرسش‌ها

- `frontend-overlay/app/App.tsx` — انتخاب صفحهٔ مهمان (لندینگ/ورود/ثبت‌نام)
- `frontend-overlay/features/auth/LoginPage.tsx` — بازگشت به صفحهٔ معرفی

## استقرار

تغییر بک‌اند لازم نیست (مسیر عمومی تعرفه‌ها از قبل وجود دارد). فقط:

```bash
npm run sync:laravel-frontend
cd laravel-backend && npm run build   # ساخت بستهٔ public/build برای cPanel
```

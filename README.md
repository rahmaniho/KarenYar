# حساب‌یار کارن سافت 💎

**اپلیکیشن جامع مالی فارسی (PWA) — کاملاً آفلاین، راست‌چین و آماده‌ی فروش**

حساب‌یار برای فروشگاه‌های کوچک، کارمندان، حسابداران و کاربران شخصی ساخته شده است: مدیریت فروشگاه و انبار، امور مالی شخصی، حقوق و دستمزد طبق قانون کار ایران و یک ماشین‌حساب حرفه‌ای — همه در یک برنامه‌ی تحت وب پیشرو (PWA) که **بدون اینترنت** کار می‌کند، روی گوشی و دسکتاپ نصب می‌شود و هیچ داده‌ای را از دستگاه کاربر بیرون نمی‌فرستد.

---

## ✨ قابلیت‌ها

### 🛍️ حساب‌یار فروشگاهی

- مدیریت کالا: نام، بارکد، دسته‌بندی، قیمت خرید/فروش، موجودی و واحد (عدد، بسته، کیلو و…)
- محاسبه‌ی خودکار **قیمت تمام‌شده** (خرید + مالیات خرید + حمل + سربار) و نمایش زنده‌ی **سود و حاشیه‌ی سود** هر کالا
- هشدار **کمبود موجودی** (موجودی ≤ حد هشدار) در کالاها، داشبورد و گزارش‌ها
- صدور فاکتور فروش: جستجوی کالا، قلم دستی، تخفیف درصدی/مبلغی، مالیات بر ارزش افزوده، **کسر خودکار موجودی** و شماره‌گذاری ترتیبی
- فاکتور قابل چاپ + **خروجی PDF** (قابلیت نسخه‌ی حرفه‌ای)
- گزارش فروش روزانه/ماهانه با نمودار، پرفروش‌ترین کالاها و سود ناخالص هر دوره

### 💳 حساب‌یار شخصی

- ثبت درآمد و هزینه با دسته‌بندی سفارشی، جستجو و فیلتر ماه شمسی/نوع
- بودجه‌بندی ماهانه‌ی هر دسته با نوار پیشرفت و هشدار «نزدیک سقف» و «عبور از سقف»
- مدیریت بدهی و اقساط: پیشرفت پرداخت، مانده، روزهای مانده تا سررسید و هشدار سررسید گذشته
- نمودار میله‌ای درآمد/هزینه‌ی ۶ ماه اخیر + نمودار دایره‌ای سهم دسته‌های هزینه
- خروجی **CSV** سازگار با اکسل

### 👨‍💼 دستمزد‌یار

- مدیریت چند کارمند (حقوق پایه، سمت، کد ملی، فرزند، تأهل، سابقه)
- محاسبه‌ی حقوق طبق قانون کار: پایه سنوات، مسکن، بن خواربار، حق اولاد، حق تأهل، اضافه‌کاری (۱٫۴ برابر)، شب‌کاری (۳۵٪)
- کسورات: بیمه‌ی سهم کارگر ۷٪ + **مالیات پلکانی حقوق** (پله‌های قابل ویرایش؛ پیش‌فرض مصوبات ۱۴۰۴)
- محاسبه‌ی **عیدی** (۶۰ روز مزد با سقف ۹۰ روز حداقل مزد) و **سنوات پایان کار**
- صدور **فیش حقوقی** قابل چاپ و PDF، با ذخیره‌ی سابقه‌ی فیش هر ماه

### 🧮 محاسبات حرفه‌ای (رایگان برای همه)

- ماشین‌حساب علمی: مثلثات (درجه/رادیان)، لگاریتم، توان، فاکتوریل، ثابت‌های π و e، تاریخچه و پشتیبانی از صفحه‌کلید فیزیکی و ارقام فارسی
- ابزار درصد، تخفیف و تغییر درصدی
- محاسبه‌ی وام و اقساط با جدول استهلاک ماه‌به‌ماه + سود مرکب و ساده
- تبدیل واحد (طول، وزن، سطح، حجم، دما)، تبدیل ارز با نرخ دستی قابل ویرایش، تاریخ‌شمار شمسی

### 🔐 سیستم لایسنس آفلاین

| سطح                | امکانات                                                   | قیمت مدل       |
| ------------------ | --------------------------------------------------------- | -------------- |
| رایگان             | ماشین‌حساب کامل، ۱ کالا، ۱۰ تراکنش                        | ۰              |
| حرفه‌ای (Lifetime) | همه‌چیز نامحدود + PDF + پشتیبان‌گیری                      | پرداخت یک‌باره |
| Pro+               | امکانات حرفه‌ای + همگام‌سازی آنلاین و چندکاربره (فاز بعد) | اشتراکی        |

- کلید امضاشده با HMAC-SHA256 + تاریخ انقضا؛ فعال‌سازی کاملاً آفلاین از صفحه‌ی تنظیمات
- گیت قابلیت‌ها با کامپوننت `<FeatureGate>` و سقف‌های نسخه‌ی رایگان
- طراحی Interface-based (`LicenseVerifier`) — قابل جایگزینی با امضای RSA یا سرور واقعی بدون تغییر بقیه‌ی کد

### 🌐 PWA و آفلاین

- Service Worker با Cache-First — بعد از اولین بازدید، کل برنامه آفلاین کار می‌کند
- نصب روی اندروید/آیفون/دسکتاپ با راهنمای فارسی، آیکون‌های ۱۹۲/۵۱۲ و Maskable
- نشانگر آنلاین/آفلاین در هدر، حالت روشن/تاریک، فونت وزیرمتن Self-Hosted (بدون هیچ CDN خارجی)

## 🚀 نصب و اجرا

پیش‌نیاز: **Node.js نسخه‌ی ۱۸ یا بالاتر**

```bash
npm install      # نصب وابستگی‌ها
npm run dev      # اجرای محیط توسعه → http://localhost:5173
npm run build    # ساخت نسخه‌ی نهایی در پوشه‌ی dist
npm run preview  # پیش‌نمایش نسخه‌ی نهایی
```

دستورهای دیگر:

```bash
npm run test            # تست‌های واحد (Vitest)
npm run test:coverage   # گزارش پوشش تست
npm run test:e2e        # تست E2E — یک‌بار قبلش: npx playwright install chromium
npm run lint            # ESLint
npm run typecheck       # فقط بررسی TypeScript
npm run license:key -- --tier pro --name "نام مشتری" [--days 365]   # ساخت کلید لایسنس
npm run icons           # بازسازی assetهای برند و آیکون‌های PWA از لوگوی اصلی (نیازمند Pillow)
```

> نکته: اسکریپت `npm run dev` به‌صورت پیش‌فرض روی `localhost` اجراست؛ برای دسترسی از شبکه یا محیط‌های ابری، Vite در این پروژه روی همه‌ی هاست‌ها گوش می‌دهد.

## 📦 راهنمای استقرار (Deploy)

خروجی `npm run build` یک پوشه‌ی `dist` کاملاً استاتیک است؛ هیچ سروری لازم نیست.

### Netlify

1. پوشه‌ی `dist` را Drag & Drop کنید یا ریپو را وصل کنید (Build command: `npm run build` — Publish: `dist`).
2. فایل `public/_redirects` از قبل داخل خروجی قرار می‌گیرد و مسیرهای React Router را به `index.html` برمی‌گرداند.

### Vercel

1. پروژه را Import کنید؛ فایل `vercel.json` در ریشه، Rewriteهای لازم و هدر ضدکش سرویس‌ورکر را اعمال می‌کند.

### هاست اشتراکی ایرانی / Apache

1. محتوای `dist` را در `public_html` آپلود کنید.
2. فایل `.htaccess` از قبل داخل خروجی هست: هم SPA Fallback را انجام می‌دهد هم کش `sw.js` و مانیفست را غیرفعال می‌کند تا آپدیت‌ها فوری برسند.

### هر هاست استاتیک دیگر (Nginx و…)

برای Nginx کافی است:

```nginx
location / {
  try_files $uri $uri/ /index.html;
}
location = /sw.js { add_header Cache-Control "no-cache"; }
```

> ⚠️ برای فعال‌شدن PWA و Service Worker، سایت باید روی **HTTPS** باشد (یا localhost). روی هاست‌های ایرانی معمولاً Let’s Encrypt رایگان فعال است.

## ✅ گزارش تست و کیفیت

| مورد                                       | نتیجه                                                                     |
| ------------------------------------------ | ------------------------------------------------------------------------- |
| تست واحد و کامپوننت (Vitest + RTL)         | **۹۷ تست — همه سبز**                                                      |
| پوشش منطق محاسباتی (`src/core` + `calc`ها) | **۸۷٪ خطوط** (هدف ≥ ۷۰٪)                                                  |
| TypeScript strict (`tsc --noEmit`)         | **صفر خطا** — بدون هیچ `any`                                              |
| ESLint                                     | صفر خطا/هشدار                                                             |
| تست E2E (Playwright)                       | ۴ سناریو در `e2e/smoke.spec.ts` (داشبورد، ماشین‌حساب، ثبت تراکنش، لایسنس) |

**عملکرد (Build نهایی):**

- باندل اولیه‌ی JS حدود **۲۰۵ KB (gzip)** با Code-Splitting صفحه‌به‌صفحه؛ نمودارها (~۱۰۹ KB) و PDF (~۱۶۶ KB) فقط هنگام ورود به همان بخش لود می‌شوند.
- CSS حدود ۶٫۶ KB (gzip)، فونت وزیرمتن ۴ وزن Self-Hosted (~۸۷ KB مجموع) و در Precache سرویس‌ورکر.
- کل اپ بعد از اولین بازدید **کاملاً آفلاین** از کش اجرا می‌شود (Precache ≈ ۲٫۱ MB شامل همه‌ی چانک‌ها).
- برای امتیاز رسمی Lighthouse: نسخه‌ی `dist` را روی هاست HTTPS بالا بیاورید و در Chrome DevTools → Lighthouse اجرا کنید؛ ساختار (PWA آماده، باندل سبک، فونت محلی) برای امتیاز ۹۰+ طراحی شده است.

## 🎨 assetهای برند کارن‌سافت

نشان و وردمارک‌های داخل برنامه (سایدبار، فوتر با اعتبار متحرک «طراحی و توسعه توسط کارن سافت»، فاکتور و فیش، آیکون‌های PWA) همگی از **لوگوی اصلی کارن‌سافت** بریده شده‌اند — هرگز متن تایپ‌شده نیستند تا فونت و رنگ برند دقیق بماند. منبع در `scripts/karensoft-logo.png` است و با `scripts/build-brand-assets.py` به `public/images/karensoft/` و `public/icons/` ساخته می‌شوند.

## 🗂️ ساختار پروژه

```
hesabyar/
├── public/                  # مانیفست PWA، آیکون‌ها، فونت وزیرمتن، fallbackهای هاست
├── scripts/                 # تولید کلید لایسنس + تولید آیکون‌ها (فقط سمت فروشنده)
├── e2e/                     # تست‌های Playwright
├── src/
│   ├── app/                 # ریشه‌ی برنامه، روتر (Lazy)، تست اسموک
│   ├── components/          # UI مشترک (shadcn-style) + FeatureGate و…
│   ├── features/
│   │   ├── store/           # حساب‌یار فروشگاهی (کالا، فاکتور، گزارش)
│   │   ├── personal/        # حساب‌یار شخصی (تراکنش، بودجه، بدهی)
│   │   ├── payroll/         # دستمزد‌یار (کارمند، فیش، تنظیمات نرخ)
│   │   └── calculator/      # محاسبات حرفه‌ای
│   ├── core/
│   │   ├── db/              # Dexie (IndexedDB) + پشتیبان‌گیری JSON
│   │   ├── license/         # سیستم لایسنس آفلاین + گیت قابلیت
│   │   ├── calc/            # توابع خالص مالی: سود، وام، مالیات پلکانی، حقوق
│   │   ├── jalali/          # ابزار تاریخ شمسی (jalaali-js)
│   │   ├── currency/        # پول (تومان/ریال) و ارقام فارسی
│   │   └── utils/           # خروجی PDF و CSV
│   ├── hooks/  layouts/  pages/  store/   # هوک‌ها، چیدمان، داشبورد/تنظیمات، Zustand
│   └── styles/              # Tailwind + متغیرهای برند کارن سافت
```

هویت بصری: سرمه‌ای `#0B1B3A` + سبز نئونی `#39FF88`، فونت وزیرمتن، گوشه‌های ۱۲px، دارک‌مود کامل.
